# PDF Imposition

Десктопная программа на Java для подготовки спуска полос
при односторонней печати.

Программа размещает четыре копии каждой страницы исходного
PDF на отдельном листе SRA3 с метками резки.

## Возможности

- Выбор одного или нескольких PDF-файлов.
- Спуск макетов А5: четыре копии на листе SRA3.
- Использование PDF-шаблона с метками резки.
- Проверка размера TrimBox: 148 × 210 мм.
- Сохранение результатов в папку «спуски» рядом с исходными файлами.
- Выбор свободного имени файла, если результат уже существует.

Например, PDF из четырёх страниц преобразуется в PDF
из четырёх листов. На каждом листе размещаются четыре
копии соответствующей исходной страницы.

## Технологии

- Java 21
- Gradle
- Swing
- Apache PDFBox 3.0.8

## Запуск

1. Установить JDK 21.
2. Открыть проект в IntelliJ IDEA.
3. Загрузить зависимости Gradle.
4. Запустить метод main в классе
   ru.anisim.pdfimposition.App.

## Использование

1. Открыть программу.
2. Выбрать один или несколько PDF-файлов.
3. Дождаться завершения обработки.
4. Найти результаты в папке «спуски»
   рядом с каждым исходным файлом.

## Требования к входному PDF

- TrimBox страницы: 148 × 210 мм.
- Поворот страницы: 0°.
- Макет может содержать вылеты за границы TrimBox.

## Основные классы

- App — точка входа.
- DesktopWindow — окно программы и выбор файлов.
- BatchImpositionService — пакетная обработка файлов.
- PdfImpositionService — создание спуска.
- ArtworkPlacement — координаты и область обрезки копии.
- ImpositionLayout — настройки варианта спуска.

Шаблон А5 находится в src/main/resources/a5-template.pdf.
