# PDF Imposition

Десктопная программа на Java для подготовки спуска полос
при односторонней печати.

Программа размещает четыре копии каждой страницы исходного
PDF на отдельном листе SRA3 с метками резки.

## Возможности

- Выбор формата: А5, А6 или А7.
- Выбор одного или нескольких PDF-файлов одного формата.
- А5: четыре копии каждой страницы на листе SRA3.
- А6: восемь копий каждой страницы на листе SRA3.
- А7: восемнадцать копий каждой страницы на листе SRA3.
- Использование шаблонов с метками резки.
- Сохранение результатов в папку «спуски» рядом с исходниками.
- Подбор свободного имени файла без перезаписи существующих результатов.

Каждая страница исходного PDF создаёт отдельный лист спуска.
Например, четыре страницы А6 дают четыре листа,
на каждом из которых размещены восемь копий соответствующей страницы.

## Технологии

- Java 21
- Gradle
- Swing
- Apache PDFBox 3.0.8

## Запуск

1. Установить JDK 21.
2. Открыть проект в IntelliJ IDEA.
3. Загрузить зависимости Gradle.
4. Запустить метод main в классе
   ru.anisim.pdfimposition.App.

## Использование

1. Запустить программу и выбрать формат А5, А6 или А7.
2. Добавить PDF выбранного формата.
   Файлы можно добавлять из разных папок.
3. Нажать «Создать спуски».
4. Выбрать общую папку назначения.
5. Результаты появятся в её подпапке «спуски».

Выбор файлов по умолчанию открывается на рабочем столе.
Для обработки новой партии другого формата очистите список.

## Требования к входному PDF

- Поворот страницы: 0°.
- Для А5 TrimBox должен иметь размер 148 × 210 мм.
- Для А6 TrimBox должен иметь размер 105 × 148 мм.
- Для А6 также поддерживается страница 115 × 158 мм,
  у которой TrimBox совпадает с MediaBox.
  В этом случае программа принимает вылеты по 5 мм
  и размещает по центру границу реза 105 × 148 мм.
- Для варианта «А7» размер TrimBox должен быть 70 × 100 мм,
  как в используемом образце спуска.
- Исходник может содержать вылеты: у проверенного образца
  размер страницы составляет 76 × 106 мм.


Программа не масштабирует макеты автоматически.

## Основные классы

- App — точка входа.
- DesktopWindow — окно программы и выбор файлов.
- BatchImpositionService — пакетная обработка файлов.
- PdfImpositionService — создание спуска.
- ArtworkPlacement — координаты и область обрезки копии.
- ImpositionLayout — настройки варианта спуска.
- ImpositionLayout — размеры, шаблон и позиции одного варианта спуска.
- ImpositionLayouts — готовые настройки А5 и А6.
